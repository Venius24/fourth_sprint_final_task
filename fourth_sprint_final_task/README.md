# Blogicum

Учебный сайт на Django 3.2: лента из трёх записей, отдельная страница записи, страницы категорий и статические страницы «О проекте» и «Правила». Данные записей находятся в `blogicum/blog/views.py`; база данных для них не нужна.

## Локальный запуск

Из папки `fourth_sprint_final_task`:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe blogicum\manage.py runserver
```

Откройте `http://127.0.0.1:8000/`. Для проверки запустите `.venv\Scripts\python.exe -m pytest`.

Для локальной разработки переменные окружения необязательны: по умолчанию включён `DEBUG` и при каждом запуске создаётся временный ключ. Если нужно сохранять сессии между перезапусками, задайте `DJANGO_SECRET_KEY`. При `DJANGO_DEBUG=false` ключ обязателен; `DJANGO_ALLOWED_HOSTS` принимает список хостов через запятую. `.env.example` показывает имена переменных, но Django не загружает этот файл автоматически. Настройки ниже относятся только к учебному локальному запуску и не являются конфигурацией развёртывания.

Шаблон ленты в этой локальной версии называется `blog/index2.html`. Проверка имени шаблона синхронизирована с этим пользовательским переименованием. Файл `index2.html` и удаление `index.html` сохранены как исходные пользовательские изменения.
