# Blogicum — первый Django-спринт

Учебный сайт: лента из трёх записей, страницы записей и категорий, страницы «О проекте» и «Правила». Данные записей заданы в Python; отдельная база для них не нужна.

Исходники, зависимости и тесты находятся в папке [`fourth_sprint_final_task`](fourth_sprint_final_task/). Перед выполнением команд перейдите в неё:

```powershell
cd fourth_sprint_final_task
```

[Инструкция установки, запуска, настройки окружения и проверки](fourth_sprint_final_task/README.md). Проверено с Python 3.12 и Django 3.2; это учебная локальная конфигурация.
